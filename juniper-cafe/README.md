# Juniper Café — Weburon sample

A responsive café demo with a filterable menu, sample pickup cart, opening hours, contact details, FAQs, and a demo owner dashboard.

Open `index.html` to preview. Once the Weburon repository is published with GitHub Pages, this site is available under `/juniper-cafe/`.

All business information and menu prices are fictional. Orders are stored only in the current browser's `localStorage`; `owner.html` only shows orders from that same browser. No real order is transmitted, no payment is taken, and this is not a production order management system. Connect a secure ordering provider and replace sample details before using this for a real café.
