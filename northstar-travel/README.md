# Northstar Journeys — Weburon sample

A responsive travel agency demo with trip filters, destination cards, a sample travel enquiry form and a browser-local owner dashboard.

Open `index.html` to preview. With the Weburon repository on GitHub Pages, this site is available under `/northstar-travel/`.

All itineraries, prices, reviews and agency details are fictional. Enquiries are stored only in the current browser using `localStorage`; `owner.html` sees only enquiries made in that same browser. There are no real bookings, payments, or agent responses. For a real agency, replace sample information, add a secure enquiry service and owner authentication, and verify legal disclosures, trip inclusions, pricing, cancellation policies and destination guidance.
